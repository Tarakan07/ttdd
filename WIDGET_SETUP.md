# Настройка виджета для Android

Виджет успешно создан и готов к использованию!

## Что было создано:

1. **Нативный Android виджет** (`TodoAppWidgetProvider`) - отображает задачи на сегодня
2. **Модуль синхронизации** (`WidgetSyncModule`) - мост между React Native и виджетом
3. **Утилиты для работы с данными** (`TaskUtils`) - хранение и получение задач
4. **TypeScript модуль** (`WidgetSync.ts`) - интерфейс для работы с виджетом из React Native
5. **Хук для синхронизации** (`useWidgetSync.ts`) - удобный хук для интеграции

## Как использовать:

### 1. В вашем хуке управления задачами (например, `useAppLogic`):

```typescript
import { useWidgetSync } from './src/widget/useWidgetSync';

// В вашем хуке:
const { syncTasks } = useWidgetSync();

// При сохранении задачи:
const handleSaveTask = async (task: Task) => {
  // ... ваша логика сохранения в AsyncStorage
  const allTasks = await getAllTasksFromStorage(); // все задачи из AsyncStorage
  await syncTasks(allTasks); // синхронизируем с виджетом
};

// При переключении задачи:
const handleToggleTask = async (taskId: string) => {
  // ... ваша логика переключения
  const allTasks = await getAllTasksFromStorage();
  await syncTasks(allTasks); // синхронизируем с виджетом
};
```

### 2. Структура задачи:

Убедитесь, что ваши задачи имеют следующую структуру:

```typescript
interface Task {
  id: string;
  text: string;
  completed: boolean;
  important: boolean;
  day: string; // 'monday', 'tuesday', 'wednesday', 'thursday', 'friday', 'saturday', 'sunday'
}
```

### 3. Добавление виджета на домашний экран:

1. Долгий тап на домашнем экране Android
2. Выберите "Виджеты" (Widgets)
3. Найдите "ToDo"
4. Перетащите виджет на домашний экран

## Особенности:

✅ Виджет показывает только задачи на сегодняшний день  
✅ Максимум 5 задач отображается в виджете  
✅ Можно отмечать задачи как выполненные прямо в виджете  
✅ Показываются пометки важных задач (звездочка ⭐)  
✅ Изменения синхронизируются в обе стороны:

- Изменения в приложении → обновляется виджет
- Изменения в виджете → обновляется приложение

## Автоматическая синхронизация:

Виджет автоматически обновляется при:

- Изменении задач в приложении (через `syncTasks`)
- Переключении задачи в виджете (автоматически синхронизируется обратно в приложение)

## Сборка:

```bash
# Для разработки
npm run android

# Для релиза
npm run android:build-release
```

## Примечания:

- Виджет использует SharedPreferences для хранения данных (синхронизируется с AsyncStorage)
- Виджет автоматически определяет сегодняшний день недели
- Все изменения виджета автоматически отправляются обратно в приложение через события
